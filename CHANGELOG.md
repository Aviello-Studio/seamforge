# Changelog

Все заметные изменения SeamForge фиксируются в этом файле.

## [2.0.0] - 2026-11-24

### Added
- Полный перенос настольного приложения с Electron на **Tauri v2 + Rust** (~6.9 МБ автономный EXE / ~2.9 МБ portable ZIP).
- Нативное декодирование аудио (`symphonia`) и автоматическое извлечение аудиодорожки из видеоконтейнеров (`MP4`, `MOV`, `MKV`, `WebM`, `AVI`, `WMV`, `M4V`, `3GP`, `MPEG`) через `symphonia` + Windows Media Foundation без FFmpeg и без ресэмплинга исходного файла.
- Многопоточный Rust DSP-анализатор (`rustfft` + `rayon`): STFT (`hop = 512`), 12-полосная chroma, дробный BPM с параболической интерполяцией, Ellis DP beat tracking без дрейфа, детектор размера (`3/4`, `4/4`), матрица рекуррентности и стерео-подгонка фазы ±25 мс.
- Интерактивный high-DPI Canvas-редактор волны с зумом, панорамированием, временной линейкой, сеткой долей и перетаскиванием границ/области петли.
- **Инспектор стыка** с осциллографом наложения конца, начала и итоговой склейки, подстройкой ±1/±10 мс, привязкой к zero crossing и выбором кривой crossfade (**Constant-Gain** / **Equal-Power**).
- Нативный WASAPI gapless-плеер (`cpal`) с кнопкой прослушивания стыка (`S`), регулировкой громкости мониторинга и Mute (`M`).
- Экспорт студийного WAV (`hound`): **16-bit PCM (TPDF-дизеринг)**, **24-bit PCM** и **32-bit float** в оригинальной частоте дискретизации.
- Кнопка «Очистить» и перетаскивание нового файла поверх уже открытого с окном подтверждения.

### Removed
- Полностью удалены Electron, Node/Python AI-рантайм (BS-RoFormer, Stable Audio 3, `uv`, загрузка FFmpeg) и настройки GPU.
